# Imágenes del Proyecto SGM-IA

Este directorio contiene las imágenes utilizadas en la interfaz del sistema.

## Imágenes Requeridas

1. **uts-logo.png** - Logo oficial de las Unidades Tecnológicas de Santander
   - Tamaño recomendado: 80x80 píxeles para el sidebar
   - Formato: PNG con fondo transparente
   - Ubicación: Colocar el archivo oficial del logo UTS aquí

## Instrucciones

1. Coloque el logo oficial de UTS en este directorio con el nombre `uts-logo.png`
2. Asegúrese de que el formato sea PNG con fondo transparente para mejor integración
3. El tamaño recomendado es 80x80 píxeles para visualización óptima en la interfaz

## Nota

Si no tiene el logo oficial disponible, el sistema funcionará correctamente pero mostrará un espacio reservado para la imagen.
